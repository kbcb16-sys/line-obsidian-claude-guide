BACKGROUND & CONCEPT

なぜこの仕組みが必要なのか？

これまでの悩み

LINEのKeepメモ、見返してますか？

移動中や作業中に思いついたアイデアや気になる記事URLをLINEのKeepメモや1人グループに送っても、結局流れて埋もれてしまい、二度と見返さない「メモの墓場」になりがちでした。

この仕組みで解決

送るだけで「第二の脳」の資産になる

LINEに送信するだけで、PCのObsidianに日付ごとのMarkdownとして自動保存。さらにClaudeに読み込ませることで、自分自身の思考やネタを反映した専属AIアシスタントが育ちます。

STEP 01

Obsidianに「LINE Notes Sync」プラグインをインストール

Obsidianのコミュニティプラグイン機能を使って、LINEのメッセージを受信・同期する専用プラグインをインストールします。

  1. Obsidianの左下にある歯車アイコン（設定）を開きます。
  2. 左側メニューの「コミュニティプラグイン」をクリックします。
  3. 「制限モード」が有効になっている場合は「制限モードを無効化」します。
  4. 「コミュニティプラグイン」の「閲覧」ボタンをクリックします。
  5. 検索窓に以下のプラグイン名を入力して検索し、「インストール」→「有効化」します。
LINE Notes Sync
💡 プラグイン情報
開発者: onikun84
機能: LINE公式アカウント宛に送信したメッセージを、Obsidian内のノートへ自動同期・保存します。
Obsidianの設定画面 (クリックで拡大 🔍)
STEP 02

専用LINE公式アカウント「ObsidianMemo」を友だち追加

スマホのLINEアプリから、メモの受け皿となる専用公式アカウントを友だち追加します。

  1. スマートフォンのLINEアプリを開きます。
  2. 友だち検索（公式アカウント検索）で「ObsidianMemo」と検索します。
  3. 該当の公式アカウント（認証バッジあり、国・地域: 日本）を「友だち追加」します。
ObsidianMemo
📌 ポイント
このLINE公式アカウントは自分専用のメモ入力窓口になります。トークルームをピン留め（お気に入り登録）しておくと、日常の入力がスムーズになります。
公式アカウント追加画面 (クリックで拡大 🔍)
STEP 03

LINEトークから「User ID」を取得する

追加した「ObsidianMemo」のトークルームを開き、連携に必要なあなた専用のユーザーIDを発行します。

  1. 「ObsidianMemo」のトークルームを開きます。
  2. 何でも良いので適当なメッセージ（例: テスト）を送信します。
  3. ボットから即座に「あなたのLINE User ID：」というメッセージが返信されます。
  4. 返信メッセージに含まれる文字列（ID）をコピーします。
テスト
⚠️ IDの取り扱い
返信された「LINE User ID」は、あなたのLINEとObsidianの保管庫を一意に紐付けるキーです。他人に共有しないようご注意ください。
LINEの返信トーク画面 (クリックで拡大 🔍)
STEP 04

Obsidian側で連携設定（IDの紐付け）

Obsidianに戻り、インストールした「LINE Notes Sync」の設定画面に取得したIDを登録します。

  1. Obsidianの「設定」＞ 左サイドバー最下部の「LINE Notes Sync」をクリック。
  2. 以下の3項目を入力します。
設定項目 推奨入力値 説明
Note folder path LINE LINEメッセージが保存されるフォルダ名
Vault ID obsidian-line 任意の識別名（英数字で自由に設定可）
LINE user ID (Step 3で取得したID) LINEボットとの会話で返信されたIDを貼り付け
  1. 入力後、「Register Mapping」ボタンをクリックして連携を完了させます。
プラグイン設定画面 (クリックで拡大 🔍)
STEP 05

動作確認：LINEにメモを送ってみる

設定完了！LINE公式アカウントにアイデアやURLを送って、Obsidianに同期されるかテストします。

  1. スマホのLINEから「ObsidianMemo」宛に、思いついたネタや参考URLを送ってみます。
  2. Obsidianを開くと、指定した LINE/ フォルダの中に、日付ごとのMarkdownノートが自動作成されます。
  3. 送信したテキストや画像が次々と自動蓄積されていきます！

FAQ & TROUBLESHOOTING

よくある質問・注意点

Q. メッセージを送ってもObsidianに反映されません

Obsidianがインターネットに接続されているか、プラグイン設定の「LINE user ID」に前後の不要な空白が入っていないか確認してください。また、プラグインの「Sync」ボタンを手動で押すことで即時反映を試せます。

Q. スマホ版Obsidianでも同期できますか？

プラグイン自体はPC版で動かすのが安定しています。スマホでも閲覧したい場合は、Obsidian公式の「Obsidian Sync」やiCloud Drive、GitHub連携（Obsidian Git）を使ってPCとスマホのVaultを同期するのがおすすめです。

Q. 写真やスクショも送れますか？

はい。動画内でも表示されている通り、画像メッセージは自動的に LINE/images/ フォルダに保存され、ノート内に画像リンクとして埋め込まれます。
